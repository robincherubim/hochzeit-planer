Link zu eurem Google-Formular

Den Link auf die Hochzeitswebsite oder in die Einladung, den QR-Code auf die Karte. Formular ansehen

Einrichtung (einmalig, etwa 5 Minuten)
  1. Am Computer euer Google-Formular zum Bearbeiten öffnen (forms.google.com).
  2. Oben rechts auf ⋮ (Mehr) und dann Apps Script klicken.
  3. Den vorhandenen Code löschen, den Code unten einfügen und speichern (Strg + S).
  4. Oben rechts Bereitstellen → Neue Bereitstellung. Beim Zahnrad Web-App wählen, Ausführen als: Ich und Zugriff: Jeder. Dann Bereitstellen.
  5. Zugriff erlauben. Kommt „Google hat diese App nicht überprüft“: Erweitert und Weiter zu …. Das ist euer eigenes Skript.
  6. Die Web-App-URL kopieren und unten einfügen.
